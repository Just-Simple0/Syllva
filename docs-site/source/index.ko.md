## 하나의 공식 문서 홈

Syllva는 원본 자료, 학업 상태, AI 검색 경계를 분리합니다. 이 사이트는 지원되는 공개 문서를 하나의 검색 가능한 화면으로 모으되, Markdown 원본은 계속 GitHub 저장소에서 버전 관리합니다.

### 목적별 시작점

- **사용자 가이드** — 학기 대시보드, 일상 학습, 파일 접수, AI 학습 흐름을 익힙니다.
- **운영자 가이드** — Syllva 설치, Drive/Notion/MCP/LMS 설정, 로컬 worker 운영을 다룹니다.
- **개념** — 아키텍처와 신뢰 모델을 설명합니다.
- **레퍼런스** — CLI 명령, 상태, MCP 도구를 정확히 확인합니다.

> Syllva **0.1.3은 미출시 베타**입니다. frozen 코어 동작 프로토콜은 계속 **1.2**이며, 패키지 버전과 프로토콜 버전은 의도적으로 독립적입니다.

## 공식 문서 사이트가 대체하지 않는 것

구현 계획, UX 리뷰 기록, handoff, frozen specification은 엔지니어링 증거로 GitHub 저장소에 계속 보존합니다. 사이트에서 연결은 제공하지만 초보자용 기본 탐색에는 섞지 않습니다.
