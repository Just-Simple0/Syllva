## One documentation home

Syllva keeps source material, academic state, and AI retrieval boundaries separate. This site brings the supported public documentation into one searchable, version-controlled place while the Markdown source remains in the repository.

### Choose a path

- **User Guide** — learn the semester dashboard, daily workflow, file intake, and AI-assisted study flow.
- **Operator Guide** — install Syllva, configure Drive/Notion/MCP/LMS, and operate local workers safely.
- **Concepts** — understand the architecture and trust model.
- **Reference** — look up CLI commands, statuses, and MCP tools.

> Syllva **0.1.3 is beta and unpublished**. The frozen core behavior protocol is still **1.2**; package version and protocol version are intentionally independent.

## What the documentation site does not replace

Implementation plans, UX review records, handoff notes, and frozen specifications remain in the GitHub repository as engineering evidence. They are linked from the site but are not mixed into the beginner navigation.
