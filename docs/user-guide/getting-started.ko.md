# 처음 시작하기

[English](getting-started.md) · [사용자 가이드](README.ko.md)

이 문서는 운영자가 워크스페이스 연결을 이미 끝냈다고 가정합니다. 저장소 설치나 provider ID/credential 설정이 아직 필요하다면 [운영자 가이드](../operator-guide/README.ko.md)를 먼저 사용하세요.

## 1. 학기 대시보드 열기

대시보드는 평소 사용하는 홈 화면입니다. 지원되는 순서는 다음과 같습니다.

1. **내 과목** — 공부할 과목으로 들어갑니다.
2. **이어서 공부** — 현재 학습 바로가기 몇 개를 보여줍니다. 자동 방문 기록 순위를 보장하는 기능은 아닙니다.
3. **To DO** — 미완료 개인 할 일과 과제 성격의 항목을 봅니다.
4. **캘린더** — 날짜가 있는 학사 일정, 과제, 시험, 개인 일정을 봅니다.
5. **파일 확인** — 자료 접수 진입점과 추가 확인이 필요한 항목을 봅니다.

모든 수업이 전역 메뉴에 나타난다고 기대하지 마세요. 먼저 과목을 열고 그 과목의 수업 목록에서 원하는 수업을 선택합니다.

## 2. 과목과 수업 열기

과목 페이지에서는 해당 과목의 수업과 관련 자료로 들어갈 수 있어야 합니다. 개별 수업 페이지는 한 번의 강의나 학습 단위를 맥락과 함께 보는 위치입니다.

메타데이터가 부족하면 Syllva는 파일명만 보고 날짜, 수업 번호, 과목을 임의로 확정하는 대신 그 불확실성을 보여주는 것을 원칙으로 합니다.

## 3. 첫 자료 추가하기

학기 intake preview가 구성된 환경에서는 다음 순서를 따릅니다.

1. PDF, 슬라이드, 전사문 등 지원되는 자료를 설정된 학기 업로드 위치에 넣습니다.
2. **파일 확인**에서 새 파일/접수 항목을 확인합니다.
3. 대상 과목과 필요한 수업/날짜/자료 의도를 입력하거나 확인합니다.
4. 요청을 명시적으로 제출합니다.
5. 적용되거나 추가 입력을 요구할 때까지 요청 상태를 확인합니다.

제출은 사람이 하는 동작입니다. 시스템 상태값을 직접 승인 체크박스처럼 바꿔 진행을 강제하지 않습니다.

## 4. 첫 학습 질문하기

연결된 AI 클라이언트에서 과목/수업 등 충분한 범위를 포함해 질문하세요. 예:

> 알고리즘 3회차의 확인된 SOURCE를 기준으로 divide and conquer를 설명해줘. 계산이 보이는 예제 하나와 사용한 자료 구간도 알려줘.

Syllva가 제대로 연결된 답변은 제한된 source-aware context를 제공하거나, 근거가 부족하다는 사실을 명확히 알려야 합니다. 부족한 근거를 자신 있게 추측해서 채우는 동작을 목표로 하지 않습니다.

## 5. 베타 경계 이해하기

Syllva 0.1.3은 호스팅 서비스나 원클릭 소비자 앱이 아닙니다. 환경에 따라 다음 작업은 운영자가 별도로 해야 할 수 있습니다.

- Drive/Notion credential과 ID 설정;
- AI client에 local MCP 등록;
- 원격 인증/네트워크 구성;
- LMS credential 및 scheduler 활성화;
- 실제 provider/client 연결 검증.

설정 후 평소 사용하는 방법은 [매일 사용하기](daily-use.ko.md)를 참고하세요.
