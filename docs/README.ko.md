## 버전 안내

현재 Syllva는 **0.1.3 beta**이며 공개 패키지 릴리스가 아닙니다. 저장소 루트의 frozen **v1.2** 문서는 코어 동작/설계 프로토콜을 설명합니다. 패키지 버전과 프로토콜 버전은 의도적으로 분리합니다.

## 엔지니어링 기록

- `plans/` — 구현 계획, 검증 계획, 운영 증거.
- `ux/` — UX 정의, 리뷰 자료, readback 기록.

이 파일들은 유지보수자와 리뷰어에게 유용하지만 초보자용 공식 경로는 아닙니다. 과거 기록은 별도 유지보수 작업에서 명시적으로 개정하지 않는 한 원래 언어와 형태로 보존합니다.
