## 실제로 등장하는 자료 종류

1. 강의 전사문(사용자 생성 녹취/필기, `.md`)
2. 강의 슬라이드/강의 노트(교수 제공, 챕터 단위: `weekN_chapM`, `Lec.NN_…(Chap.X)`, `Chapter 0X-…`)
3. 실습 자료(`weekN_lab`, 실습 안내 PDF)
4. 제공 소스코드(학습용 예제: `tcp_server.c 소스 파일`, `fgets_ex.c 소스 코드`)
5. 과제 안내(Assignment 본문/첨부: Lab 과제, 실습과제 NN, 과제 1·2·3)
6. 과제 참고 자료(과제에 딸린 데이터셋·서식·참고 코드: `mbti`, 프로젝트 서식)
7. 환경 설정 안내/설치 프로그램(VMware, Ubuntu, OpenSSH 설치)
8. 과정 소개/강의 계획(`00-과정소개`, `Lec.00_강의소개및실습안내`)
9. 보조 자료(Appendix, 참고 문헌, 교재 일부)
10. 녹화 강의/회차 항목(날짜 제목 ExternalTool)
11. 시험 관련(중간고사 공지, 기출문제)
12. 공지(점수 공개, GitHub 안내 등)와 학생 제출물(계획서·발표) — 교수 SOURCE가 아니므로 intake 대상 제외 후보

## 시사점

- 제목만으로도 2·3·4·7·8은 규칙으로 높은 확률 분류 가능하다. 5·6·9·11은 내용 확인이 필요하다.
- 소스코드와 데이터셋은 현재 체계(`TRANSCRIPT`/`MATERIAL_PDF`)에 자리가 없어 `UNSUPPORTED`로 빠진다.
- 과목 배정은 Drive 업로드 파일명 또는 Canvas 모듈 출처로 결정적이고, 주차·날짜는 모듈 위치/제목에서 얻는다.
